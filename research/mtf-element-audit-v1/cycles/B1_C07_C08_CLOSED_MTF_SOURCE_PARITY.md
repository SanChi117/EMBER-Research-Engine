# B1/C07 — закрытые 1H/4H/1D из первичных 15m Futures и независимый контроль 1D

**Дата:** 2026-10-15. **Приёмка:** `SOURCE_BOUND_CLOSED_15M_RESAMPLING_AND_NATIVE_DAILY_PARITY_PASS`, только инженерный слой, **не** академический Daily Bias/Order Flow/POI/VC и **не** торговый сигнал.

## Причина

Имеющийся C08 реестр 315 проверенных архивов включает исходные Binance USD-M Futures серии **15m и 1d**, но не содержит самостоятельно подтверждённых исходных 1h и 4h. Учебная TDA-схема `d05/C02_TDA_SOURCE_ROUTE_TOPOLOGY.json` требует 1D/4H/1H/15m/5m по конкретному маршруту. Нельзя выдавать 15m за 4h/1h, автоматически называть любой IMB «4H VC POI», выводить дневное направление из одной свечи или использовать незакрывшийся старший бар.

Поэтому B1/C07 делает **только техническую** UTC-агрегацию:

- 1H из 4 последовательных полностью закрытых 15m.
- 4H из 16 последовательных полностью закрытых 15m.
- 1D из 96 последовательных полностью закрытых 15m.
- OHLC: O первой, H максимум, L минимум, C последней. Объём — точная сумма `Decimal` исходных строк. `known_at_ms` старшего бара = закрытию последнего исходного бара.
- Сырые бары обязаны быть только BINANCE USD-M FUTURES, одной монеты, иметь уникальный `member_id`, точный временной шаг и **известное начало UTC-дня**. Пропуски и несмежные свечи → отказ. Неполная свеча старшего ТФ не входит в выдачу.
- Каждая построенная свеча хранит `source_member_ids`. В чистом unit-ресэмплере эти ID **не являются проверкой Binance-происхождения**: это делает отдельный C08 ZIP-probe.

## Попытка опровержения и остаточные ограничения

1. Тесты отвергают потерянные 15m, смешанный рынок и таймфреймы, дубликаты источников, невыравненную границу UTC и попытку появиться полной 1D из 95 свечей.
2. Исходные ZIP считаются подтверждёнными только в рамках HTTPS/TLS + .CHECKSUM *с того же хоста* и frozen C08 SHA; сторонней криптографической цифровой подписи нет.
3. **1H/4H являются воспроизводимой агрегацией 15m, а не отдельно проверенными исходными 1H/4H Binance свечами.** Сверка с ними остаётся независимой задачей.
4. Данный прогон охватывает **один день одного инструмента**. Он не перепроверяет математически 315 архивов, ранее прошедших C08, и не доказывает равенства агрегации/оригинального 1D в каждом дне/на каждом инструменте.
5. 1D за этот день становится известна **только в 00:00 UTC следующего дня**. Нельзя использовать OHLCV этой свечи для решения на 1H/4H/15m внутри самого дня 2026-10-01. Для внутридневного MTF-контекста нужен предыдущий **уже закрытый** 1D с прежним `known_at`.
6. Дневной bias, 4H Order Flow, raid/fractal, POI, trigger и Volume Confirmation должны иметь **отдельную академическую семантику с авторской разметкой**. Исходная схема задаёт только последовательность старших и младших TF. Никакой route READY/SL/TP/PnL не утверждается.
7. Никакой live trading, SMOKE, V5, QFVG или ключи не затронуты.
