## 2. Новая независимая техническая модель

`d05/c49_original3m_post_contact_directional_close.py` получает полную source-проверенную последовательность оригинальных **native3m** из C21 и неизменённую C46 candidate/contact provenance. Для каждой original 4H source wick-gap зоны `bottom/top` рассматривает **только свечи, у которых START >= CLOSE original3m свечи первого контакта**. Саму свечу касания пропускает: её OHLC не доказывает порядок прохождения уровня и реакции.

Для LONG source:
- **благоприятное закрытие** = *первая* более поздняя 3m свеча с `close > top`;
- **противоположное закрытие** = *первая* более поздняя 3m свеча с `close < bottom`.

Для SHORT определения симметрично меняются. Точное равенство границе — НЕ выход. Если у свечи длинные тени одновременно проходят обе границы, но close остаётся внутри, это **не** фиксированный порядок стопа/тейка и не триггер. Сохраняются `source native3m row ID`, `close known-at`, exact Decimal-цена свечи. Первое полное закрытие в одну из сторон останавливает поиск, даже если после него цена пересекает границу обратно.

Три **не подбираемые по доходности ADAPTED временные альтернативы** (с момента закрытия свечи первого контакта): **1h, 4h, 12h**. Если полное окно ещё не прошло и не было выхода — `NO_LATER_DIRECTIONAL_CLOSE_WINDOW_OPEN` (right-censored). Если прошло — `NO_LATER_DIRECTIONAL_CLOSE_HORIZON_COMPLETE`. Ненаблюдавшийся first 4H source contact отмечается отдельно.
