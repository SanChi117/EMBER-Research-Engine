Ветви на основании оригинального текста академии:

- Daily POI / Liquidity → 4H VC; при авторски валидном 4H тесте → 1H Trigger → 15m VC (IMB/SNR).
- Если 1H Trigger не образован либо на 4H Liquidity Raid → 1H VC/new POI → её реальный первый тест → либо 15m Trigger → 5m VC (IMB/SNR), либо direct 15m VC (IMB/SNR) без Trigger.
- Дополнительная логика: настоящий первый тест, не повторный визит; RB — две разнонаправленные свечи, рейд ликвидности или контакт с IMB и nuance wick/body; различать 4H IMB и вложенный 1H IMB в неразрешённых случаях. Route B IDM и Route C Raid→BOS не смешиваются.

**Граница адаптации:** исходные физические wick-пересечения считаются исключительно `SOURCE_TECHNICAL`; рабочие допущения маркированы `ADAPTED_HYPOTHESIS`. 4H индекс C46 не становится авторским 4H first test; raw 3m first wick — не авторский 1H first valid test; source 15m IMB/SNR — не доказанный Trigger или direct VC; aligned native5m source geometry — не доказанное 5m VC.
