**Дата:** 25 октября 2026 UTC. **Область:** BTCUSDT/ETHUSDT/SOLUSDT/XRPUSDT/BCHUSDT, Binance USD-M Futures, 01.09–02.10.2026, PAPER ONLY / NOT_TRADE_READY.

## Почему этот цикл нужен

Согласно исходному `Fair Value Gap  Imbalance.txt` на Google Диске, первый тест настоящего POI имеет принципиальное значение: последующие возвращения могут сформировать пул ликвидности, который позже снимут. Это **правило академии про авторски выбранный POI**, а не утверждение, что любой трёхсвечный 4H wick-gap автоматически торгуется. Для воспроизводимой проверки реализовали лишь **жизненный цикл технических пересечений 4H gap**, не заявляя о валидности его реакции, SL или о выполненной сделке.

## Принцип source chronology

- [x] Исходная 4H техническая IMB-кандидатная зона образуется только после **закрытия всех трёх 4H-свечей**; её first touch по оригинальному native3m бару обязан в точности совпадать с прежним независимым C46. Запрещены intrabar future high, lookahead.
- [x] Ряд original3m wick overlap с [bottom,top] считается непрерывным **одним эпизодом посещения**: любое число подряд идущих 3m свечей внутри зоны не превращается в дополнительные «тесты». Отдельный повторный source visit допускается только после **хотя бы одной целиком закрытой 3m свечи вне зоны**. В рамках одной OHLC-свечи несколько проходов цены не восстанавливаются и не придумываются.
- [x] Если 4H source возникает ровно на последнем закрытии доступного файла, ни одной будущей 3m свечи ещё нет: это правомерно **без наблюдений**, а не ошибка. Если последний эпизод контакта ещё продолжается при конце источника — он явно **правосторонне цензурирован**. Никакой авторский `first valid POI test` от простого wick пересечения не появляется.
- [x] Каждому исходному source visit сохраняются first/last original ZIP SHA:bar_start ID, start/known time, число подряд пересекающих зону закрытых свечей, был ли complete out-of-zone departure; данные не конвертируются в order/fill.
