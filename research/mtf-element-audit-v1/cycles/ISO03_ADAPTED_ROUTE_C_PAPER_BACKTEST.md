# ISO03: adapted Route C paper backtest

**PAPER ONLY · NOT_TRADE_READY. Это не авторская стратегия и не доказательство прибыли.**

ISO03 добавляет исполнение поверх ISO01/Route C, не меняя semantic gate E и не объявляя технические наблюдения авторскими сигналами.

## Фиксированные adapted-правила

- Направление: `BSL raid → SHORT`, `SSL raid → LONG`.
- Из 3m/5m child выбирается событие с самым ранним `known_ms`.
- Вход: первая native 3m свеча, открытие которой наступило не раньше `known_ms`.
- ATR: простое среднее True Range предыдущих 14 закрытых 3m свечей.
- Stop: `1.5 × ATR`; target: `2R`; time stop: 120 3m свечей (6 часов).
- Если SL и TP находятся внутри одной свечи, консервативно засчитывается SL.
- Gap через SL исполняется по открытию, а не по более выгодной цене стопа.
- Одна позиция на инструмент; сигналы во время позиции пропускаются, а не ставятся в очередь.
- Риск 1% текущей model equity, не более 3× leverage; комиссия 0.05% за сторону, проскальзывание 0.02% за сторону.
- Funding, ликвидация и заёмная маржа не моделируются. Параметры не оптимизировались.

## Исходные данные и проверка

- 160 ежедневных Binance USD-M native 3m ZIP: пять инструментов × 32 дня.
- 76 800 original 3m bars; каждый ZIP проверен по SHA-256 из pinned manifest.
- 542 ISO01 parent-сигнала; ISO01 заново восстанавливается из frozen C56.
- 116/116 tests PASS на Python 3.10.22, 3.11.2 и 3.12.12: ISO01 40, ISO02 46, ISO03 30.
- Входов раньше `signal_known_ms`: 0. Открытых позиций в конце: 0.
- Accounting delta: `5.82e-11` на начальные 100 000; допустимый float residue, не пропущенная сделка.
- Полный результат во всех версиях побайтово одинаков: 1 755 781 байт, SHA-256 `2ef7ff3f18982eff0e0bca4d2f5017387f4dbd000360b92788cbb77f4d92192a`.

## Результат base adapted

Начальный model capital: 100 000.

- Сделок: 384; пропущено сигналов: 158.
- 113 прибыльных, 271 убыточная; win rate 29.427%.
- Выходы: 268 STOP, 114 TARGET, 2 TIME_STOP.
- Net PnL: **−80 345.90015**; return **−80.3459%**.
- Final equity: 19 654.09985.
- Profit factor: **0.40244**.
- Max drawdown: **81.7036%**.
- Комиссии: 54 108.11171.

## Контроли издержек, не оптимизация

- Без комиссий и проскальзывания: 385 сделок, **−7.1447%**, profit factor 0.95798.
- Комиссии без проскальзывания: 385 сделок, **−69.0207%**, profit factor 0.52686.

Контроли меняют equity и, следовательно, equity-dependent sizing; это не paired-trade counterfactual. Главный вывод: adapted-правило убыточно даже без издержек, а базовые издержки существенно ухудшают результат. Подгонки параметров не выполнялось.

## Ограничения

Один 32-дневный период — не OOS и не статистическое доказательство будущего результата. Отсутствуют funding и liquidation model. Этот backtest пригоден для воспроизводимой проверки механики и отбраковки adapted-гипотез, но не для live и не для утверждения, что авторская стратегия проверена.
