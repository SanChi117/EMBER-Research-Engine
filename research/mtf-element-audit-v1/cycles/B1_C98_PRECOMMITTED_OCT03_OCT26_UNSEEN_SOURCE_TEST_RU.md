**Новый период исторического контроля:** UTC 2026-10-03 00:00:00 (включительно) — 2026-10-27 00:00:00 (не включая). **24 полных дня.** Эти даты отсутствовали в исходных 266400 native5m и 76800 native3m источниках C92/C93/C94. Не считать «абсолютно девственным» будущим, поскольку календарное время октябрьских торгов ранее обсуждалось пользователем; относиться как к свежему, не использованному в этих бэктестах периоду.

**Вселенная** без изменения: BTCUSDT, ETHUSDT, SOLUSDT, XRPUSDT, BCHUSDT, Binance USD-M. Только оригинальные архивы Binance Vision **daily 5m** для A/B и **daily 3m** для C, один ZIP на дату/символ/таймфрейм, каждый ZIP требует Binance `.CHECKSUM`, SHA256 ZIP/CSV, точный единственный CSV и 288/480 нативных строк и целостную временную последовательность (временная отметка свечи, отсутствие gap, корректные OHLCV). Если нет одного архива — тест невалиден, не подменять данными другого провайдера/таймфрейма. Каждый оригинальный 15m должен идентично реконструироваться как 3×5m и 5×3m по OHLCV, иначе STOP.

**A/B** — тот же C91 и C94 алгоритм с неизменённым кодом и неизменённым первоначальным стартом 2026-04-01. Прогрев D1/W1 и предыдущие структуры должны содержаться в полной апрель–октябрьской базе; сравнить полную прежнюю историю с замороженным C92/C94 до 2026-10-03 за вычетом 12h A / 20h B embargo. Считать только сделки входа >= 2026-10-03 и полностью закрытые <= 2026-10-27. Исключить повторно посчитанные или обрезанные позиции.

**C** — тот же C93, без изменения алгоритма и без подмены 3m на 5m, источник сентябрь–октябрь 3m + новые 3m; сохранить тип native3m и 15m parity. C93 рассчитан строго на 32-дневном окне; применить заранее определённое **окно 2026-09-25–2026-10-27** (ровно 32 полных дня), данные до 3 октября только для прогрева. Выводить отдельно 1H Raid→3m BOS, не смешивать граф с A/B. Нулевое число сделок — допустимый честный ответ.

**Прогнозная проверка:** количество, gross/net R, Win rate, Profit Factor, max drawdown при иллюстративном 1% риска на 1R. Стоимость полного оборота **14 / 25 / 40 базисных пунктов**. Для каждой модели не заявлять устойчивость при n<10, net R <= 0 на 25 bps, PF <= 1.2 на 25 bps, условная DD >= 10%; критерии строгие и НЕ ЗАМЕНЯЮТ более длинный настоящей future walk-forward. Отдельно показывать календарное предписание, что C-модель имеет меньший исторический pre-roll.

**Силовое правило:** если нет реальной исходной истории, нет сравнения, есть провал хеширования, свечей, OOS или тестов — FAIL-CLOSED. Не улучшать RR и не отбирать «победителей» по данной выборке; любые последующие изменения только под новым хешированным исследовательским протоколом.
