# EMBER C82 — проверка состава доказательств академии без подмены авторских меток

Дата: 2026-10-26. Вход: C81/A151 (151/151 SHA).

В основе: точные C73/C72 original Binance USD-M crypto исходные архивы,
проверенная C81 очередь **153** исходных контекстов. C82 не скачивал
новых ZIP и не имеет новых авторских положительных/отрицательных goldens.

## Результат

Каждому контексту соответствует **не торговый сетап**, а список
внешних доказательств, которые *нужно получить* для авторской проверки.

- P0 = 12 выбранных 1H source POI → source 15m → позже source 5m.
  Необходимо получить авторские положительные/отрицательные примеры:
  валидный первый тест POI, 15m Trigger против direct 15m VC,
  истинный 5m VC, и исходный crypto timestamp.
- P1 = 23 физические 3m касания без ясной 15m цепочки:
  нужен авторский valid-first-test и отрицательный 15m контрпример.
- P2 = 71 противоположная/неоднозначная 1H ветка:
  требуется проверить авторскую отбраковку, а не считать это авторским
  negative golden.
- P3 = 47 без выбранной новой 1H POI:
  нужны исходный 4H parent и 1H контекст; касания посторонних зон
  не приравнивать к first-test новой 1H POI.

Модуль `d05/c82_independent_owner_media_request.py` создаёт
только неизменяемые пакеты с `owner_auth_status=NOT_AUTHENTICATED`.
Исходный C81 объект не принимает самоназначенные метки author,
фальшивые review-attestation, orders/fills/trades, неверные ключи или
пропуски причинного порядка 1H→3m→15m→5m.

эффективности стратегии, 153 торговых входов или полученных media
goldens. Положительных и отрицательных авторских crypto labels = 0.
