# C116 / FROZEN PRECOMMIT — единый original 1m источник и ценность подтверждения 5m на 4H POI

Дата 2026-10-30 UTC. PAPER ONLY, все реальные и автономные торговые исполнения запрещены. Фиксируется **до скачивания новой C116 истории**. Не является восстановлением C109 и не переписывает C114/C115.

## Экономический тезис

Условное основание преимущества: после первого касания подтверждённой 4H FVG часть участников закрывает противоположное направление либо переносит ликвидность; подтверждённый **закрытой 5m свечой 2L2R CHoCH** должен повышать вероятность достижения заранее известной 4H встречной FTA-цели раньше 4H SL. Это пока ГИПОТЕЗА, а не доказанные ликвидации/обязательный order flow.

Фальсификация: T=4H first touch + подтверждённый 5m CHoCH за 6h vs C=то же первое касание 4H FVG без CHoCH на общей отметке t0+6h. Дополнительно placebo-перестановки меток внутри уже сопоставленных T/C пар (объяснительный RANDOM LABEL контроль; **это не независимый random-market-entry**). Не приписывать placebo причинный эффект и не выдавать случайные перестановки за торговые исполнения.

## ОДНА новая семейная методика источника

Первоисточник на каждом символе/UTC день = **одно** original Binance Vision USD-M native1m daily ZIP + официальный .CHECKSUM, ZIP и CSV SHA256, строго 1440 закрытых UTC-свечей, полный OHLCV, no gaps/duplicates, closed_time=t+60s−1, объём и кол-во сделок конечны и >=0. Максимальный ZIP=30MB и запрет лишних ZIP members.

Из независимого *одного canonical native1m* потока строгой (не интерполированной) UTC агрегацией строим:
- 3m = 3 original1m, каждые 480 свечей/день, тип Original3mRow с as-of known_ms;
- 5m = 5 original1m, каждые 288 свечей/день, тип Bar из прежнего C114;
- 15m, 4H и 1D — только последующая агрегация original-derived 3m через исходный C105.
Все 3m/5m 15m OHLC обязаны совпадать ровно, т.к. они получены из одной поточной цены. Если оригинальные независимые 3m/5m Биржи расходятся, фиксировать их только как внешний diagnostic witness, без подмены и без записи успеха источника на основании этой самосогласованности. **Преимущество этого источника — внутренняя непротиворечивость, а не доказательство истинной истории.**

Volume является архивным quality diagnostic, **не** входным фильтром. Результаты C114 2025-01-14 и C115 2023-11-14 исключены из C116 испытательных окон.

## Нулевые контроли

1. Основной: matched no-CHoCH controls from same 4H POI family and risk strata, **общий timestamp t0+6h**. Отчёт all treated, all controls, ITT, unmatched и matched отдельно.
2. Статистический placebo: **2000** независимых парных перестановок T↔C с фиксированным seed `11620261030`, для каждой исходной matched пары обменять метки по монете-неделе с фиксированной псевдослучайной последовательностью. Наблюдаемая парная разница netR25, эмпирический односторонний p (с +1 поправкой), доля случайных результатов >= наблюдаемого. **Не подменять** исходный block bootstrap 2000 seed 11420261030.
3. Отчёт long и short отдельно с n, realized netR25/40, PF, stop first, timeouts, R/ITT, а также BTC-beta correlated concurrent fills. **Ни один постфактум сегмент не используется как gate или фильтр.**

**Важное ограничение:** placebo-метки проверяют ассоциацию conditional on matched cohort, но не являются тестом независимого random-entry с теми же SL/TP. Такую отдельную альтернативу можно зарегистрировать в C117 лишь после проверки реализуемости source-only без просмотра C116 outcomes.

## PASS / FAIL / NO_POWER — не смягчать после просмотра котировок

Каждое окно должно содержать >=40 matched CHoCH / no-CHoCH пар, >=10 matched пар по каждой половине. На matched T 25bps netR>0, PF25>1.2, PF40>1.1; T−C mean netR25>0 с lower95 block-bootstrap по symbol-week>0; T TP-before-SL строго выше C по общему окну и отдельно обеим половинам; adverse-wick DD<10% при 1% starting-equity risk. **Все условия** в обеих выборках обязательны. Дополнительный placebo p<0.05 на обоих окнах — *ещё одно* обязательное подтверждение; при несоответствии исходному bootstrap порогу нельзя объявить PASS.

Если число matched пар мало — NO_POWER (а не 'починим' CHoCH для n). Если original1m источники отсутствуют, повреждены, имеют clock gaps или данные интервала не закрыты — SOURCE_BLOCKED. Если тесты движка ошибочны — ENGINEERING_BLOCKED, не выдавать экономику. Исторический PASS разрешает только новый prospective PAPER test, не реальные средства. Реальные биржевые сделки: **LIVE BLOCKED в любом исходе**.
