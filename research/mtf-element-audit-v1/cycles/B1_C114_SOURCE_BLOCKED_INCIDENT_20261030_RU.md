# C114 / A177 — SOURCE_BLOCKED, без экономического вердикта

2026-10-30. PAPER ONLY. Исходный предкоммит C114: cycles/B1_C114_PRECOMMIT_INDEPENDENT_4H_POI_5M_REACTION_PREDICTIVE_VALUE_RU.md.

## Что действительно сделано

- Реализованы независимый парсер оригинальных Binance USD-M 5m ZIP с provider .CHECKSUM и SHAs, и исследовательский движок «4H FVG first touch -> native5m 2L2R CHoCH -> common 6h landmark -> 4H target/stop».
- 23 негативных теста source, хронологии, подтверждённых 5m pivot и matched controls прошли для Python 3.10/3.11/3.12; регрессии C105/C109/C113 прошли.
- Реальные 3m и 5m исторические daily ZIP загружены в CI и проверены по индивидуальному checksum; архивные данные в GitHub не сохранены, потому что источник не прошёл cross-interval compatibility.
- Первый full replay: GitHub Actions https://github.com/SanChi117/EMBER-Research-Engine/actions/runs/41108159716 — не прошёл 15m parity на BNB, bucket index 1302, до открытия какой-либо сделки.
- Диагностический full replay: https://github.com/SanChi117/EMBER-Research-Engine/actions/runs/41108544181 — на том же bucket index 1302 **OHLC price+time parity PASSED**, но volume parity не прошёл: 3m aggregate 24700.27 BNB, 5m aggregate 31675.04 BNB; относительная разница **22.019766983719673%**, что намного выше зафиксированной 0.01% (1 bp) границы.

В C114 **нет экономических результатов, сделок и PF**, поэтому C114 не FAIL стратегии, а **SOURCE_BLOCKED**. Ни одна доходность не подменена и не экстраполирована.

## Проверка причин и обязательная честность

Исходный C114 предкоммит требовал независимых оригинальных 3m + 5m и абсолютной верификации часов; дополнительная cross-15m volume проверка была введена в инженерной реализации. После первого source mismatch (ещё **до расчёта сделок**) диагностическая amendment разделила strict OHLC (обязательное совпадение) и менее существенную для price-only модели volume tolerances (не более 1bp). Архив показал **22%**, не десятые погрешности округления. Мы НЕ переписали допуск, чтобы объявить тот же C114 «зелёным» после просмотра источникoв.

Риск для стратегии: все формальные POI/ATR/SL/TP и CHoCH использовали только OHLC, но 22% независимое расхождение объёма заставляет отдельно проверить источник, а не выдавать подлинность checksum за согласованность интервалов.

## Решение

1. **C114 strict source experiment = SOURCE_BLOCKED.** LIVE BLOCKED, экономических утверждений НЕТ.
2. Сохранить исходную ветку и CI с отрицательными свидетельствами, не лечить post-hoc правила на открытой выборке.
3. Новая самостоятельная source-family должна прежде проверить реально независимые временные потоки только для price-based модели: SHA проверены, UTC непрерывны, **OHLC 15m строго совпадают**, а метрики объёма записываются как отдельный non-traded data-quality diagnostic без заднего числа при зафиксированных новых периодах.
4. Если 15m OHLC mismatch когда-либо наблюдается => SOURCE_BLOCKED без экономического вердикта. Если исследование пройдёт на новой выборке, статистика и match controls должны пройти прежние экон. критерии, не облегчённые из-за этого инцидента.

Никаких реальных ордеров, финансирования или торговых рекомендаций. Строгий экономический gate C114 остаётся нетронутым, без подбора параметров.
