# Порядок следующих независимых циклов, без бэктеста прибыли

- C04: **D01 — отдельный контракт BarClosed**. Определить обязательные поля и source, `as_of` и UTC alignment, незакрытая свеча и отсутствие объёма должны приводить к reject. Попытаться сломать неправильным типом интервала, duplicate, gap, future-close, timezone-offset, prefix Spot/Futures. Испытать на 2025/2026 независимых CSV без выбора параметров. Только затем формальный signoff.
- C05: **D02/D03 — event-time & TF synchronization**. Проверять переходы с 1H, 4H, 1D и 1W, неделю Monday UTC, delayed/right-confirmed swings и as-of snapshots; обязателен негативный пример со старшей ещё незакрытой свечой.
- C06: **D04 — архивы/источники**. Проверить историю с SHA256 официального ZIP, поля market-type, отдельный протокол январской аномалии 2025. Источники Spot и Futures несовместимы.
- C07: **L01 — обычный swing** (не IDM). Учебная разметка позитив/негатив, подтверждение только после правых свечей.
- C08: **L02–L05 — BSL/SSL, EQH/EQL и рейды**. Постепенно по одному элементу с явными ценовыми шкалами или качественной ручной разметкой без притворной точности.
- C09+: **P02/P03/P04/P05** (IMB, OB, RB, SNR), затем P09 (StrongHL), T03 (IDM), T04 (BOS3m/5m), T07 (FTA).

В каждом из этих циклов: гипотеза → негативный случай → позитивный случай → независимый повтор → запись в chained log → сомнение/слабые места → статус. **Нет валидной записи — нет выполненного шага.**
