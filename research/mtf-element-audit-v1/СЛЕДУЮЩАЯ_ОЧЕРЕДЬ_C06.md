# Очередь после C05

1. **C06 / D03 — event lineage:** идентификаторы событий, родительские зоны/источники, временная доступность, запрет связывать дочернее подтверждение с зоной, созданной позже. Проверять в отдельном модуле; готовые события пока не означают торговые сигналы.
2. **C07 / D04 — источник:** проверка внешних официальных архивных CHECKSUM, конфликт января 2025, случаи ложного source_description. До этого D01/D02 ограничены локальной целостностью.
3. После самостоятельной смысловой аттестации структурных элементов: POI, Liquidity, Raid, VC, IDM, Strong High/Low, FTA, затем маршруты входа. Не переносить статусы D01/D02 на распознаватель сетапов.
4. Ни один новый компонент не подсоединён к терминалу или реальной торговле.
5. Отрицательные тесты, неудачные прогоны, журнальные записи и облачные сверки должны быть сохранены для каждого цикла.
