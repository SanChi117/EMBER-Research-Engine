# MTF — проверяемый журнал и отчёты опровержений

**Статус:** первый цикл аудита оснований, **НЕ** новая торговая стратегия и **НЕ** разрешение на тесты прибыльности или LIVE.

## Как пользоваться

1. Открыть `ЖУРНАЛ_ДЕЙСТВИЙ.jsonl` — он содержит последовательные A001+, ссылки на материалы и хэши.
2. Открыть `cycles/C00_...`, `cycles/C01_...`, `cycles/C02_...` — у каждого цикла есть гипотеза, прямая проверка, попытка опровержения и заключение.
3. Проверить запись и доказательства: `python tests/test_journal_integrity.py` (после распаковки всех файлов).
4. При запуске каждого следующего действия вызвать `python tools/auditlog.py record ...` **после появления файла доказательства**, проверить, что оно действительно содержательное.
5. `МАТРИЦА_ПОСЛЕ_ОПРОВЕРЖЕНИЙ.json` — дельта поверх исходных 45 паспортов. Исходная спецификация остаётся неизменённой.

### Итоги

- 45/45 паспортов согласованы по ID, пять мутаций реестра распознаны.
- **0/45** содержат точное поле первоисточника (нужна трассировка).
- На 8 синтетических сценариях найдено **4** пробела контракта низкоуровневого CSV-loader.
- Проверенные 2026 USD-M CSV (**93 600 ×15m и 975 дневных cross-check**) прошли независимо; это **не** противоречие — старые бэктесты проходили отдельный строгий gate.
- Тест самоконтроля журнала обнаруживает три типа умышленной подмены.
- Историческая ложная запись A003 **сохранена и явно инвалидирована A004**, не замаскирована.
- Ни один модуль распознавания POI/IDM/BOS/FTA сейчас не аттестован на визуальных учебных эталонах.

### Что дальше
