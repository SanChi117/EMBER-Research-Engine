## Проверка причинности и значения опорного BOS

Сопоставлены пары `ACCUMULATION_LOCKED`, `SWEEP_RETURN`,
`STRUCTURE_BREAK_CONFIRMED` по одному candidate_id, без просмотра будущих исходов.

| Факт | Число |
|---|---:|
| Все BOS | 234 |
| Уровень локального BOS внутри исходного диапазона накопления | 212 |
| Pivot BOS подтверждён **после** фиксации накопления | **206** |
| Pivot BOS подтверждён не позднее фиксации накопления | 28 |
| Pivot BOS подтверждён на самой свече SWEEP_RETURN | **29** |
| Возраст pivot при выносе <= 1 часа | **157** |
| Pivot существовал <= 4 часа до выноса | **232** |
| При BOS присутствовал ранее обнаруженный FVG | 148 |

**Вывод:** большое число `STRUCTURE_BREAK_CONFIRMED` означает пробой
недавно сформированного локального pivot, а не обязательно структурный
перелом, относящийся к заранее зафиксированной фазе накопления.

Это не lookahead: pivot по времени известен до самого BOS. Но
поисковый алгоритм выбирает опору поздно. В действующем MSR-01 при SWEEP
используется последний 15m pivot на момент SWEEP, а не pivot,
замороженный при ACCUMULATION. Нельзя выдавать эти варианты за эквивалентные.

CI эти числа не объявляются.
