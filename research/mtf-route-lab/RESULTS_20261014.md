## Портфель (условный старт $1 000)

Правила: 0,5% модельного риска на позицию, максимум две одновременно, номинал не более 3× капитала. Моделируются касание лимита на OHLC, SL первым при конкуренции SL/TP, комиссии + проскальзывание; **нет** реальных подтверждений исполнения, спреда по стакану, funding, tick/lot ограничения, ликвидаций и удержаний в реальном времени. Просадка — **bar-close mark-to-market** по 15m, не внутрисвечный worst case.

Параметры издержек: BASE комиссия 0,05% **на сторону** + slippage 0,02% на сторону; COST_X2 0,10% + 0,04% на сторону. **Число сделок различается между сценариями**, поскольку стратегия фильтрует сигнал по Net RR с учётом издержек. Поэтому лучшая на вид доходность отдельных сравнений *не* является доказательством снижения транзакционных потерь.

## Техническое исправление портфеля

В первом GitHub Actions прогоне обнаружился `duplicate signal id`, потому что независимый движок создавал одинаковые ID при одинаковых событиях **на разных монетах**. В учёте сделок идентификатор теперь `symbol|source_id`; оригинальный `source_id` сохранён в журнале. **Алгоритм создания Entry/SL/TP, MTF 0.3 и три маршрута не изменялись**.

Тестов **118 PASS** (115 старых + 3 идентичности). Повторный прогон портфеля дал побайтово идентичный `FINAL_SUMMARY.json` (SHA256 `ff092f328d2e09084d1165ff312a3018e1793988ece7e9a5830104ed27d07afe`).

## Не выполнено

- Нет 30–50 независимо визуально подтверждённых исходных учебных эпизодов: `course_visual_labels_verified=0`.
- StrongHL/POI частично proxy; BOS 15m — **не** первичный BOS 3–5m.
- Нет независимой untouched OOS, tick/lot/funding/mark price и исполнения по биржевому стакану.
- Macro/news/OI/funding контекст не реконструирован point-in-time как полноценный фильтр; запись UNKNOWN не блокировала сигналы.

**Вывод:** на этой Futures-истории текущая автоматическая MTF-аппроксимация не дала преимущества. Менять параметры ради хороших цифр без разрешения пользователя запрещено.
