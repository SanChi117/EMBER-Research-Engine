## Почему этот кандидат, а не ещё одна случайная стратегия

- Независимый открытый рейтинг Freqle: [dip_catcher](https://freqle.org/strategy/...) / [League snapshot](https://freqle.org/ranking); в сводной таблице 2022–2024 на 33 парах заявлены **+747.5% net, PF 1.37, MaxDD 6.71%, 21.1k trades**, 5m futures, winrate 87.9%. Это результат **третьей стороны с её собственной методологией**, НЕ воспроизведённый нами; может отличаться по параметрам, комиссии, universе, ценам, version и исполнению. Цифры не служат основанием для торговли.
- Публичный исходник: `viktors1982/trading` pinned commit `e572140b1b8cb550cb244c67d363087b81bd4ab8`, путь `freqtrade/strategies/dip_catcher.py`, Git blob `76ab2b3f91dc7beaa0be8021a245caa2b3f4186f`; автор указывает Freqtrade-порт оригинального Haehnchen dip catcher.
- Original source: `can_short=True`, `timeframe=5m`, `minimal_roi={"0":0.03,"30":0.02,"60":0.01}`, `stoploss=-0.08` (РИСК ВЫШЕ ЦЕЛЕВОГО!), trailing_stop=False, без adjust_trade_position / DCA / leverage override. Original `order_types` entry/exit LIMIT, stop MARKET, stop_on_exchange=False.
- Сигналы: HMA, Bollinger, облако Ichimoku на 5m; по коду `shift(displacement)` только положительный для линий облака (ранние значения сдвигаются в будущее); отрицательных `shift` и центрированных вычислений в оригинале не найдено. Это исходный скрининг, не полная доказанная каузальность.
- Исходный STOP 8% цены против ROI 3%→1%, может давать длительные зависшие сделки, **не удовлетворяет нашему окончательному требованию короткого стопа и частого закрытия**. Допускаем тест только для оценки наличия экономического сигнала (последующая адаптация — новая стратегия и обязательно новый неиспользованный OOS).

- Никаких изменений опубликованного исходника, включения новых фильтров, переоптимизации, выбора символов после просмотра результатов. Проверка exact source blob/commit, Freqtrade `2026.4`.

- Два `--fee` сценария 0.0005 BASE и 0.00125 STRESS на каждое исполнение (в исходной стратегии LIMIT, эти цифры — принудительная модель, не реальные maker-tier комиссии). Дополнительный slippage/spread/queue не учитываются, поэтому даже стресс остаётся оптимистичным. Each native ZIP + trade receipts SHA256.
- Гейт экономического ИССЛЕДОВАНИЯ (не допуска к исполнению): минимум 2 из 4 пар в ОБОИХ сценариях с N≥35, net>0, PF≥1.2, max wallet DD<15%, top3 winning <60%; суммарно >=141 трейдов/141 день в каждом сценарии на 4 независимых wallets. No phantom one-wallet combined profit.
