# A202 — независимая проверка неблагоприятного хода (MAE) старых выигрышей, НЕ бэктест нового стопа

Дата 31.10.2026. Ручной повторный разбор именно 8 подлинных native ZIP, artifact 13025456717 SHA256 `fd57dc5685bab819e768ed6a3c1134bb421421f485751d43d94d4a03d1b86df6`, Freqtrade 2026.4 original `dip_catcher` May13–Sep30 2026. Только BASE fee 5bps. Original LONG & SHORT, no DCA, 1x, source stop8%.

Для каждого `roi` профитного trade со значениями `open_rate`, `min_rate`, `max_rate`, `is_short`:
- LONG: `MAE=max(0,open_rate-min_rate)/open_rate`;
- SHORT: `MAE=max(0,max_rate-open_rate)/open_rate`.

Для разных гипотетических узких стопов считаем долю старых ROI-win, которые **хотя бы раз за удержание** достигали соответствующего adverse excursion. **Это НЕ доказывает, что стоп сработал раньше цели**: в одной OHLC свече последовательность тиков неизвестна, при смене стопа изменяются последующие позиции, частота, funding, комиссии, PnL. Никаких модификаций оригинала/экономики этой оценкой нет.
