## Разбор механизма
- 2025 BTC 3 сделки (3 LONG, 0 SHORT), 2025 LINK 4 (2+2). 2026 ETH 5 (0 LONG, 5 SHORT), LINK 2 (1+1).
- 2025 BTC максимальное удержание **550 мин (9ч10м)**; 2025 LINK **1275 мин (21ч15м)**. Обе >90m, исходный `custom_exit` декларирует закрытие при 90 мин; native лимитный выход может зависнуть без исполнения — **parity gate FAIL**. Указанное внешним Freqle среднее46ч не совпадает с целью TTL90m, поэтому необходимо моделировать nonfill/exit fallback до каких-либо адаптаций.
- Повторный вход на следующей 5m свече: **0 случаев**; занятость всех четырёх слотов **0%** в 2025/2026 (98.6% для отвергнутого dip_catcher). Занятость здесь не проблема; проблема экстремальная нехватка входов.
- Исходная стратегия действительно обнаруживает события реакции от предшествующего S/R уровня; но совокупность 48×5m POI+RSI+EMA200+Volume/Wick фильтров и авторских лимиток на 4 majors даёт 7 сделок/годовой 141-дневный отрезок, т.е. **ни близко к пользовательской цели 3–5 A+ сделок/день**. Из данных нельзя различить частоту сырых сигналов и число неисполненных входных LIMIT без отдельного signal→limit-fill parity audit.

## Решение без переоптимизации
**A205 — отклонена как ГОТОВАЯ стратегия.** Не менять 48→24, RSI/EMA/touch tolerance, не брать выгодный LINK как единственную монету после тестов и не утверждать прибыль по 2–4 сделкам. Полезно сохранить только причинную идею: прошлый S/R + реакция + короткая экспозиция + event one-shot, но отдельно тестировать в новом исследовательском протоколе.

**Новая критическая метрика:** raw event count vs filled limit entries; 90m callback scheduled vs fill timestamp; нельзя называть среднее исполнение «через 90 мин» по одному исходнику. Прежде чем пробовать новый вход, измерить исполняемость лимиток: сигнал есть ≠ сделка произошла.

A206 должен искать оригинальные 5m/15m LONG+SHORT с NO DCA, практической частотой, ATR/структурным стопом 0.5–1.5% движения цены, явным **market exit fallback** для TTL и доказанной работой обеих лет. Сначала исходники, затем prereg и бэктест. Никаких реальных торговых действий.
