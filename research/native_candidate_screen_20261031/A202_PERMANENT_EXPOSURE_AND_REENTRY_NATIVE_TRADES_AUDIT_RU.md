# A202 ORIGINAL dip_catcher — проверка экспозиции и повторных входов (по native ZIP)

Source: A202 GitHub Actions 41156913032 artifact 13025456717; 4 pairs BTC ETH SOL LINK, BASE fee0.0005, STRESS0.00125, 2026-05-13—2026-10-01. Вывод основан не на рекомендациях и не на подогнанной торговой стратегии, а на всех оригинальных `trades` `open_date/close_date` из подлинных 8 native ZIP.

## Независимая методика
Для каждого из 8 genuine ZIP берём оригинальные открытие/закрытие. По четырём монетам одновременно строим `[(timestamp,delta=+1 open), (timestamp,delta=-1 close)]`, сортируем; интервалы считаем от test start до test end. Time-weighted occupancy — `seconds_with_n_open/141 days`. У каждого символа по предрегистрации максимум 1 позиция. Дни без позиции НЕ выбрасываем. Сделки на границе могут force close. Никакие новые сделки или выходы не добавляются.

## Повторный вход

Для BASE каждого символа сортируем `trades` по `open_date`, вычисляем `next.open_date - previous.close_date`:
- BTC: 66 последовательных промежутков, **100% ≤5min**, median **5min**.
- ETH: 95 промежутков, **100% ≤5min**, median **5min**.
- SOL: 145 промежутков, **100% ≤5min**, median **5min**.
- LINK: 160 промежутков, **100% ≤5min**, median **5min**.
**Всего 466 из 466** переходов — повторный вход не позднее чем через 5m. Это отдельный убедительный индикатор, что оригинал торгует почти перманентный regime, а не подтверждённые событийные setup.
