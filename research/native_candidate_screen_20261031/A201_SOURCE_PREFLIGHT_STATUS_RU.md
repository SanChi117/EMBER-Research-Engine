## Аудит оригинальных исходников
- `TheoBrigitte/freqtrade@c9def379b1036064d592c3a0518a07811f5a9a76`
- `momentum_wick.py` blob `1377a5bbf454252ca835cca3056787ac8ed73c04`: 5m, `can_short=True`, вход при трех подряд трендовых свечах+небольшой фитиль. Два направления включены. SL -0.10 и ROI +0.02, без trailing. Явного отрицательного shift/центрированного окна не обнаружено в коде входов. Полная lookahead-analysis пока НЕ выполнена.
- `momentum_rsi.py` blob `3f839276f661f242a30e4dd1aa0b739459e7d65b`: 5m, SHORT=1 по 3 направленным свечам, ниже SMA200; `enter_long=0` (LONG НЕ работает по оригиналу). SL -0.10 и ROI +0.02. Явного обращения к будущим свечам в signal rules нет.
- Исходная геометрия обеих стратегий: риск 10% цены ради 2% цели. Для фиксированной ставки без иных выходов без учёта комиссии требуется >83.33% попаданий по TP, чтобы закрыть убытки по SL. Реальная динамика exit signals/stop может менять этот порог; **это не прогноз winrate**.
- Отсечённые исходники: RsiquiV2 и RsiquiV5 используют `numpy.gradient` (центрированная производная на внутренних точках): на истории [20,25,40,60] последняя производная =20, но если добавить позже бар 48, производная той же прошлой точки становится 4; forward-looking dependency доказана математически. Время такой исходной сделки на прошлом баре недоступно тогдашнему трейдеру.
- Не смешивать параметры оригинала и последующие исправления; оригинал должен быть протестирован неизменным, а затем отклонён либо оставлен только исследовательским кандидатом.
