## Фиксируем испытание заранее
- Engine `freqtrade==2026.4`, оригинальная стратегия, futures isolated, **1x leverage** (в исходнике leverage override отсутствует), 1000 USDT модельный кошелёк/монета/стратегия, fixed stake 100 USDT, max_open_trades=1 на каждую отдельную монету, без DCA.
- BTC/ETH/SOL/LINK Futures, период [2026-05-13, 2026-10-01) UTC, реальные 5m Binance Vision price, 1h mark и settlement funding из контрольных A195/A196.
- Два уровня комиссии: 0.0005 и 0.00125 на каждое исполнение, прочие параметры полностью неизменны. Комиссии обе стороны, slippage/spread не моделируются => оптимистичность, даже стресс не подтверждает живое исполнение. Native Freqtrade ZIP+JSON trade journals SHA256 сохранить.
- Порядок: оригинальный исходник Git blob→подлинный Freqtrade→сырые трейды→гейт. Без подгонки параметров, выбора монет постфактум или смешивания 4 кошельков в один выдуманный.
- Первичный исследовательский гейт на **каждую** стратегию независимо: минимум **2 из 4** монет одновременно на обоих тарифах N>=35, net>0, PF>=1.20, max DD<15%, доля top3 выигрышных сделок <60%; суммарно не менее 141 завершённых сделок на 4 раздельных кошельках/141 день на каждом тарифе.
- Независимый period после публикации конкретной стратегии/периода не доказан; May–Sep 2026 уже неоднократно использовался => это **исследовательский повторный скрин**, не pristine OOS. Ни один положительный результат не разрешает торговлю.
- Геометрия оригинала SL 10% цены против TP 2% цены ≈ начальный RR 0.2 до комиссии. Для нашего малого депозита такой риск сам по себе не соответствует целевому короткому стопу; стратегия не допускается в исполнение даже при статистическом PASS без отдельной непереобученной модели риска.
- `momentum_wick` содержит деление фитиля на тело; проверка результатов на zero-body обязательна. `momentum_rsi` LONG=0 — честно фиксировать как шорт-онли.
- Lookahead: явного отрицательного shift/centered gradient в этих источниках не найдено, но реальный `lookahead-analysis` после экономического PASS остаётся обязательным.

## Отрицательные исходники, отклонены на аудите без финансового прогноза
- RsiquiV2/RsiquiV5: `numpy.gradient` по всему историческому вектору зависит от будущих значений → НЕ каузальный технический сигнал без преобразования кода.
- VolatilitySystem из официального репо: оригинальный stoploss -1.0, ROI=100, увеличение позиции; не соответствует малому депо и короткому стопу.
- TrendFollowingStrategy и FSupertrendStrategy из официального repo: SHORT сигнал указан, но `can_short` не включён → SHORT не активен в стандартной стратегии.
- WTX3: stoploss -0.7 при 10x и без предохранительного ограничения; не соответствует допустимому риску.
