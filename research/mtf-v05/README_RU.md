# MTF Route Lab 0.5 — адресное исправление lifecycle 4H POI

Дата 2026-10-14. Только PAPER. Старое ядро `mtf_engine.py` (SHA256 `3d430361a7654b460281e76b1cb976c2a89676388a5adeb752049550992e6d46`) не изменено.

## Подтверждённая ошибка

После инвалидации 4H POI часовым закрытием старые связи `triggers` и `childvc` продолжали выдавать идеи 15m. Исправлено в `mtf_engine_v05.py`: **каждая** ветка A, B(1H→15m), B4(4H→1H) и C перед `entry_quote()` повторно проверяет parent на точный момент `known` сигнала. Отклоняются несуществующие/инвалидированные parent и старые тесты. Для B4 непосредственный новый `4h VC→1h IDM` не требует повторного касания 4H POI. Старый порог invalidation и все FTA, RR, издержки не изменены.

## Что намеренно НЕ переписано

- Неполная геометрическая причинность 15m-детектора, неподтверждённые StrongHL/IDM/RB/SNR/FTA proxies.
- Учебный 3/5m BOS всё ещё отсутствует: маршрут C является 15m proxy.
- Не добавлен торговый запрет на повтор parent без графических эталонов (учёт `PARENT_REPEAT_IDEA_AUDIT_ONLY` добавлен для исследования).
- Модельный стоп, комиссия, slippage, рычаг, TTL и портфельный лексикографический порядок A/B/C заморожены для честной сравнимости.
- Недоказанная причинная связь через 1W/1D глобальный контекст остаётся аудируемым недостатком.

## Независимые парные тесты

Обе эпохи и все сценарии зафиксированы **до просмотра результатов v0.5**: 2026-04-01..2026-10-12 и 2025-02-01..2025-12-31, пять Futures-монет, 2 FTA × 2 fee/slippage. Данные загружаются из двух уже успешно валидированных GitHub Actions artifacts по ID, затем сравниваются SHA256 с baseline по каждому символу, TF и сценарию. Ни оптимизации порогов, ни смешения Spot нет. Источники 2025 содержат заранее исключённый январь из-за конфликта архивов 2025-01-29.

Контрольный BTC 2026-05-22 12:15 UTC: исходный `4h:IMB_LONG:1779393600000:` должен **не** порождать идею после 09:00 инвалидации. Другой parent, если действителен, может законно породить идею в то же время — тест проверяет **parent_id**, а не только таймстамп.

`results_v05/{2025,2026}/V05_COMPARISON.json` включает независимые решения каждой ветки, отклонения, таблицу сделок, portfolio OHLC PnL и разницу с замороженным baseline.

Важно: успешный bugfix и PF >1 в отдельном периоде, если встретится, **не** является подтверждением торгового преимущества; нет размеченных учебных графиков и проспективной проверки.
